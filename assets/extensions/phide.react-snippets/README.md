# Phide ES7+ React / TypeScript / Next.js Snippets & IntelliSense

Complete JavaScript, TypeScript, React 18/19, Next.js App Router, Redux, and React-Native snippets and IntelliSense natively integrated into **Phide IDE**.

## Features

- **175+ ES7+ React, TypeScript, Redux & React-Native Snippets**:
  - Functional & Arrow Components: `rfc`, `rfce`, `rafc`, `rafce`, `rfcp`, `rafcp`, `tsrfc`, `tsrfce`, `tsrafc`, `tsrafce`, `rmc`, `rmcp`
  - Class & Pure Components: `rcc`, `rce`, `rpc`, `rpce`, `tsrcc`, `tsrce`, `tsrpc`, `tsrpce`
  - React Hooks Snippets: `useStateSnippet`, `useEffectSnippet`, `useContextSnippet`, `useReducerSnippet`, `useCallbackSnippet`, `useMemoSnippet`, `useRefSnippet`, `useImperativeHandleSnippet`, `useLayoutEffectSnippet`
  - ES6/ES7 Imports & Exports: `imr`, `imrd`, `imrs`, `imrse`, `imp`, `imd`, `exptp`, `expint`, `nfn`, `anfn`
  - Console & Debugging: `clg`, `clo`, `cer`, `cwa`, `cin`, `ctm`, `cte`, `ctl`
  - Redux & React Native: `rcredux`, `rfcredux`, `tsrcredux`, `rnf`, `rnfe`, `rnfs`, `tsrnf`, `tsrnfs`
- **Full React 19 + React DOM Type & Hook IntelliSense**:
  - Complete hooks (`useState`, `useEffect`, `useMemo`, `useCallback`, `useRef`, `useReducer`, `useContext`, `useTransition`, `useDeferredValue`, `useActionState`, `useOptimistic`, `useFormStatus`, `use`, etc.) with automatic imports and `"use client"` support.
  - Full `React.*` TypeScript namespace completions (`React.FC`, `React.ReactNode`, `React.CSSProperties`, `React.ChangeEvent`, `React.MouseEvent`, `React.ComponentProps`, etc.).
- **Complete JSX / TSX / SVG / ARIA / Next.js Attribute IntelliSense**:
  - All HTML, DOM event handlers (`onClick`, `onChange`, `onSubmit`, ...), WAI-ARIA (`aria-*`), SVG (`viewBox`, `strokeWidth`, ...), Next.js (`<Image>`, `<Link>`, `<Script>`), and local custom component props.
