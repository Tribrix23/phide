# Phide Developer Feature Plan & Codebase Audit (50 Core Features)

This plan inventories **50 high-value, everyday software engineering IDE features**—excluding AI/LLM integrations, chatbots, and gimmicks—audited directly against Phide's current C++20 source tree (`src/` and `include/phide/`).

> **Audit Note:** Early design sketches in `docs/` (`ARCHITECTURE.md`, `UI_SPECIFICATION.md`) predate the active implementation. All statuses below reflect actual wired behavior verified in `src/` and `include/phide/`.

## Implementation Roadmap Status (50 / 50 Implemented)

All planned phases (P0–P3) across Categories 1–7 have been implemented and verified in `src/`, `include/phide/`, and `tests/test_verification.cpp` (`[TEST 125]`–`[TEST 132]`):
- **Phase P0–P1 (`#1`–`#25`, `[TEST 125]`–`[TEST 127]`)**: Core text editing, multi-cursor, column selection, inline Find/Replace, Quick Open / Workspace Search / Peek Definition / Cross-File Rename / Navigation History & Bookmarks, multi-server LSP, rich Hover & Signature Help, Problems panel, Code Actions, CodeLens, and Inlay Hints.
- **Phase P2 (`#26`–`#30`, `#33`, `#35`, `#37`, `[TEST 129]`–`[TEST 130]`)**: Compare Two Files, 3-Way Git Merge Conflict resolver, Stash & partial Hunk staging/revert, multi-backend `DapClient` interactive debugger (Variables/Watch/Call Stack/Exceptions), Integrated Test Explorer, `.vscode/tasks.json` & script DAG Task Runner, and ANSI Terminal Problem Matchers.
- **Phase P3 (`#41`, `#42`, `#45`, `#48`–`#50`, `[TEST 131]`–`[TEST 132]`)**: `LiveServer` WebSocket/SSE live-reload & Nginx/PHP presets, native SQL Query Console (`SqlEngine`), Remote SSH/WSL/DevContainer VFS & command/task/LSP wrapper, hierarchical `.editorconfig` & `.phide-workspace` multi-root support, editable `KeyboardShortcutsView` + `.phide/settings.json` + GUI Snippet Editor, and Win32 `>50 MB` memory-mapped file viewing with budgeted delta undo.
