# Phide Developer Feature Plan & Codebase Audit (50 Practical Features)

This plan inventories **50 everyday, practical software engineering features** that developers actively rely on in a native IDE—**excluding AI/LLM integrations, prompt bars, fake-AI prediction heuristics, and non-essential algorithms**—audited strictly against Phide's current C++20 source tree (`src/` and `include/phide/`).

> **Audit Scope & Excluded Non-Essential / AI Systems:**
> - **AI / ML / Ghost-Text Bloat Excluded:** External LLM connectors (`0` occurrences) and local synthetic/ML helpers (`FloatingPromptBar`, `PredictionEngine` / `ZedPredictionData`, Bayesian/Markov `AdaptiveCodeEngine`, `SemanticCommitEngine`) are intentionally excluded from this developer roadmap.
> - **Non-Essential Algorithms / Telemetry Excluded:** Visual force-directed node topology (`GraphView` / `MoreDependencyGraph`) and gamified contribution heatmaps (`ActivityHeatmapView`) are excluded in favor of practical daily coding, debugging, Git, terminal, database, and workspace tooling.
> - **Reality Check:** Every status below reflects actual runtime wiring in C++, including dead `AppConfig` toggles, stubbed menu items, and missing UI links.

- **Not Implemented** — Absent from the codebase, or exists only as an un-wired stub or empty placeholder.
